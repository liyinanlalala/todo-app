# 产品概述

Todo App — 一个全栈待办事项管理应用。

## 当前状态

项目处于早期阶段，前端使用 Vite + React + TypeScript 脚手架初始化，尚未实现任何业务功能，仅包含 Vite 默认模板页面。

## 目标功能

- Todo 增删改查（列表、添加、勾选完成、删除）
- 用户认证（注册 / 登录，JWT + bcrypt）
- 前后端分离架构

## 规划路线

详见 `todo-app-roadmap.md`，分为 5 个阶段：

1. Phase 0 — 环境准备
2. Phase 1 — 前端搭建（React + Vite 配置）
3. Phase 2 — Node.js 后端（Express + Prisma + PostgreSQL）
4. Phase 3 — 容器化（Docker + Docker Compose）
5. Phase 4 — CI/CD + 部署（GitHub Actions + Railway / Vercel）
